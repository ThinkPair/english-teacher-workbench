英语班主任工作台 · Mac 版 0.2.0
状态：离线运行组件已打包，尚未在真实 Mac 上启动验收。

这是什么
这是与 Windows 0.2.0 相同的教师工作台，包含教材真题库和针对性练习。
包内同时包含 Apple 芯片（M 系列）与 Intel 芯片运行组件，启动时自动选择。
不需要另外安装 Python、Node，也不需要输入命令。请使用 macOS 11 或更新系统。
本包不是 iPhone/iPad 应用，也不是已经签名、公证的 Mac App Store 应用。

第一次打开
1. 在 Mac 上用“归档实用工具”完整解压 ZIP，保留 EnglishTeacher-Mac 整个文件夹。
2. 双击“启动英语班主任.command”。会出现一个启动窗口，稍后在默认浏览器打开工作台。
3. 显示“工作台已打开”后可以关闭启动窗口。平时双击同一文件即可重新打开。
4. 若系统阻止启动，请保留具体系统提示；此包尚未完成实机验收，不要关闭系统安全保护。
5. 如需退出后台服务，双击“停止英语班主任.command”。关闭网页本身不会停止后台服务。

操作入口
左侧“教材与真题库”导入 PDF 或照片，分类后保存。
文字 PDF 可在本机搜索。扫描页/照片可按 1–8 页交给 AI 拆题，或者手工录题。
确认入库后，在学生档案点击“针对性练习”，按老师确认的学校失分筛选原题。
保存练习后可以分别查看学生卷、教师答案，也可以记录复测。
题库不足会提示缺题，不会生成题目冒充真实来源。
当前示例是虚构材料；“个人资料库”初始为空。

AI 和资料
上传、保存和本机检索无需 API。AI 识别、拆题及教案需在“模型设置”填写服务地址、模型与密钥。
识别图片所选的模型必须支持图片输入。真实识别质量需要实际试卷逐题验证。
模型设置为老师本人共享，示例与个人资料分别保存，两个空间共用这份设置。
Mac 版 API 密钥保存在仅当前账户可读的本机设置文件里，并非 Apple 钥匙串加密。
Windows 版使用 Windows 账户加密，两种方式不同；不要把 Windows 的设置文件复制过来。
资料备份不包含模型密钥。换电脑后在软件里重新填写自己的密钥。

资料在哪里
教学数据：~/Library/Application Support/EnglishTeacherWorkspace/runtime/
在 Finder 的“前往文件夹”可粘贴上面的路径。
数据不在下载的程序文件夹里。更换程序文件夹时保留上述数据目录。
请定期使用侧栏“下载当前空间备份”；两个空间分别备份。
不要将已有 runtime 数据或 settings.json 打包发给其他人。

出现问题
保留启动窗口中的提示，以及数据目录下的 mac-startup.log 和 application.log。
日志可用于定位问题；分享前请检查其中是否包含个人信息。
本包只完成组件来源/校验和、架构、路径、启动脚本与资料隔离的静态检查；Mac 实机启动、系统权限弹窗、打印和模型连接尚未验证。
项目的“使用说明.md”解释共同功能，其中 Windows 启动、数据路径和加密部分以本说明的 Mac 规则为准。
本地服务只监听 127.0.0.1:8769。没有向公网部署，也不含任何真实学生资料或用户 API 密钥。

组件与许可
Python 运行组件来自 astral-sh/python-build-standalone 的官方公开发布。
Python 库来自 PyPI，原许可证保存在各 wheel 的 dist-info 及 THIRD_PARTY_NOTICES 中。
使用 PyMuPDF/MuPDF 的 AGPL 许可方案；应用源码随包提供。三个参考项目只用于理解流程，未直接复制其应用源码。
