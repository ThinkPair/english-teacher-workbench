## 高价值攻击场景

1. 示例和正式空间使用不同存储键；正式空库、损坏库、读写异常均不得自动变成示例档案。
2. 使用 A 的成绩、标签或计划 ID 搭配 B 的学员 ID，编辑必须拒绝；删除 A 只级联 A 的关联记录，其他学员完整保留。
3. 非法 JSON、重复 ID、孤儿引用、非法日期、空值/无穷成绩、错误版本不能改动原库；写盘失败保留旧状态和草稿；过期窗口不能静默覆盖；恢复使用当前空间的递增修订号。
4. 建议仅取当前学员证据，不自动改标签、成绩或计划；转计划仅打开可编辑草稿，保留证据快照。不同考试仅提示得分率与可比性限制。
5. 名称、备注等包含 HTML/事件字符串时按文字渲染；异步导入/删除中切空间不得落到新空间；原始备份不得沿用上一空间内容。
6. 版本 1 全量校验后迁移为版本 2，保留原编号、修订号及字段；非法旧库拒绝。科目缺省补空、长度/类型越界拒绝、多余字段剥离；旧调用方编辑时省略科目保留原值，显式空字符串才清空。
7. 标签重复与薄弱/强项冲突按同一学员、规范化科目和标签判定，跨科可同名；成绩建议不混科、不串学员。语文及空科目的“过去”不触发英语时态动作，空科目只用通用建议。

## 已发现并关闭的问题

**P2：浏览器切空间读取失败时，原始备份沿用上一空间内容。**

- 复现：正常读取示例空间，令下一次存储读取失败，再切正式空间。旧实现进入错误页，但 `expectedRaw` 仍保留示例 JSON；反方向可能把正式内容带入示例错误页。
- 修复：每次读取开始清空原始缓存并记录读取是否成功；未读成功不展示原始导出；动作处理器亦检查当前原始内容可读。
- 独立复验：回归用例确认缓存不沿用、按钮不出现、直接调用导出动作也不会下载。10 / 10 浏览器逻辑测试通过。

**原生切空间失败后的草稿上下文：** 确认放弃后若切空间读取失败，旧表单曾失去保存上下文。现仅在实际离开或切换成功后清除草稿；读取失败保留原上下文和未保存状态，原生模拟回归通过。

**空科目被当成英语：** 空科目弱项曾触发英语启发式，与“不推断旧记录学科”的合同不一致。现空科目采用通用动作，明确英语才触发英语规则；独立核心最终 69 项包含此回归。

## 已核边界

原生页面模拟验证了存储失败不发布新状态、磁盘变化拒绝覆盖、篡改已校验导入文字后必须重验、挂起删除中切空间拒绝执行、建议只建立草稿。源代码检查未发现 HTTP 地址或 fetch、XMLHttpRequest、WebSocket、wx.request/uploadFile/downloadFile/cloud 调用；这是代码范围核对，不是生产网络流量证明。

单老师单设备、本地无登录的交付不提供多个现实教师间的账户隔离；同一浏览器/设备可见同一正式空间。示例/正式分键不是操作系统安全隔离。备份包含当前空间全部学员信息，应仅放在可信私人位置。

未完成微信真机、真实软键盘、剪贴板和缓存配额检查；独立测试没有评估实际教学效果、市场采用或付费意愿。注册与官方模拟器加载不证明认证、备案、类目或平台审核完成。
