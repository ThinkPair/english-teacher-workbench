# 学员手记 0.4.0：分类饼图与全类成绩同图

首页以实心饼图显示全库各类档案占比，图例可选择分类。下一张图将本类当前科目全部学员放在共同日期轴内，每人一条线、各取近六次非未来同科记录。默认全画，不截前N人；点姓名只突出对应曲线，其他线保留淡化。下方紧凑档案名册可搜索和筛待跟进，不减少全类图的曲线。个人档案仍保留单人成绩图。

比较以实际记录的满分为准：所有入图成绩满分一致时画原分，否则自动显示得分率并说明。修改分类默认满分不重算历史；不同学科分别选择，未知学科暂不入图。无成绩者保留姓名图例、不补零；同日记录共享横坐标，不编造顺序测评。末端编号避让时由同色细引导线连接真实末点。
