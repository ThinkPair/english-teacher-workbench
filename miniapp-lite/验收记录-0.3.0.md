# 学员手记英语版 0.3.0 候选验收

当前首个小程序专注英语教学，支持小学、初中、高中自由填写年级。可自定义教学分类名称与默认满分，年级保留为学员信息。新建档案默认固定英语、预选当前分类，保存后进入本人详情。首页按分类展示构成及各档案最近六次成绩折线。10名虚构学员直接放在同一库内，均可普通编辑和删除，删空后不重新注入；没有独立示例模式。

## 数据兼容与边界

格式为 schemaVersion 4，包含分类及学员分类引用。旧 v1/v2 全量校验后只在明确科目唯一时推导档案学科；v3已有学科和示例标记保持。旧1/2/3分类留空、学员归未分类，不猜归属或改旧成绩。隐藏的班级字段、编号、满分及已有记录保留。已有非英语档案不会被本版静默改成英语；旧未分类成绩和通用标签编辑备注时不自动补英语。新 archive 优先，坏库不回落到示例；两个旧存储键不删除，旧示例仅可明确确认后单独复制。

单老师、单设备、本机存储；无云同步、在线账户、外部 AI、支付或团队隔离。建议来自已记录的标签与成绩规则，须由教师核对选材；不是学生能力诊断。容量上限 900 KiB，真实缓存限制和设备故障仍可能导致写入失败。
