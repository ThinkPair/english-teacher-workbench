# 0.3.0 英语分类版官方模拟器视觉复核

2026-10-06，官方微信开发者工具，390×844模拟画布。图片和业务操作均用合成存储夹具，不读取真实学员记录。

根整合与独立页面复核已看 `wechat-simulator-0.3.0/10-final-home.png`、`20-category-settings.png`、`21-empty-category.png`、`03-new-archive.png`、`08-tag-shortcuts.png`，未发现阻断问题：首屏完整显示首张折线及卡片底部，分类名/满分/管理入口清楚，新增学员与标签表单不挤压，空分类可直接建档。

根整合还复核最终普通导航版本 `11-final-cards.png`、`12-bottom-chart.png`、`13-long-label-zero-full.png`：滚动折线不再穿过底栏，长称呼换行，同日0%与100%坐标正确，缺失无虚构零分。构成卡实测约136px逻辑高度。表单保存与底部空状态按钮在较矮屏幕需滚动，不冒充全部内容同时出现在首屏。

最初直接Canvas与覆盖导航仍出现安全区穿透，最终采用离屏Canvas生成本机临时图片并由普通image显示；底栏回到普通view。绘图导出失败/异步过期/卸载保护由独立测试覆盖，不代表所有机型已验证。

原生业务验证分两段完成：主流程17项，导航及空库3项。自动化曾在页面返回后的过渡期使用元素导致传输超时；续验改为等待实际路由和视图稳定，三导航实际点击及帮助返回通过。段信息保存在 `wechat-simulator-0.3.0/flow-result.json`，不把传输超时写成应用数据丢失，也不把逻辑mock说成真实手机落盘。

当前尚待iOS/Android真实软键盘、触控、缓存与剪贴板验收；同一源码绑定见 `../release/official-validation-receipt-0.3.0.json`。
