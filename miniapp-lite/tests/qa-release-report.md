- v1 → v2 只补缺省科目，保留修订号和记录，不改输入；孤儿、重复 ID、非法日期／数值与错误状态不能借迁移通过。

- 建议不借其他学员证据、不跨科比较、不自动保存；空科目不推断英语。混科和未分类视图不画混合趋势。

- 帮助页跳转保留未保存表单；引导关闭不写学员数据；科目与待跟进筛选不改变数据归属。
- 当前 JS 源码未见网络、云、登录、支付、读取剪贴板、分享朋友圈／聊天能力；启动与打开帮助未触发复制。此项是源码及模拟调用检查，不是实机网络抓包证明。
