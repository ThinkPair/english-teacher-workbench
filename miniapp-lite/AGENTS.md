**2026-10-07 上架进度：** 个人主体已由用户确认及后台读回。0.6.1 已上传开发版本（227979 bytes），修正复制失败时残留成功提示的问题；本版 168 项合成回归通过；名称“学员手记”、头像与简介已保存；服务类目“工具 > 办公”显示“已通过”并已设为主营。后台仍显示未备案、未认证；认证提示不影响后续版本发布。用户已表示点完隐私确认；实际进入指引设置页，原选项“完全不处理信息”与代码不符，已切换到“处理信息”，但确认按钮仍不可用，尚未展开明细或验证保存。不得再把同一初始协议当作待用户确认，也不得认定隐私声明已完成。手机验收、体验版配置、代码提审及发布未完成。见 [上传记录](release/upload-receipt-0.6.1.json)、[后台设置记录](release/backend-setup-receipt-20261007.json) 与 [类目办理记录](release/backend-category-receipt-20261007.json)。

本轮先做好覆盖小学、初中、高中的英语教师原生工具：新档固定英语，按教师自定义分类归组，每类有默认满分，年级保留为档案个人字段。单库内放可编辑删除的示例，首页展示全库分类实心饼图、当前类别与科目的全员共享日期轴折线，以及紧凑档案名册，没有空间切换和班级表单。公开文案不写私人身份，名称学员手记已于 10-07 在后台完成设置。按 [CONTRACT.md](CONTRACT.md) 与 [design-contract.md](design-contract.md) 实施，用户最新消息及根 Agent 分配优先。通用核心可留供未来复用，本轮不启动其他项目。保留桌面版，不读取或迁移 runtime/release 真实数据。

- 根 Agent：整合、原生存储迁移、配置/预览、真实模拟器及最终验收；负责验收记录和 QA 汇总。
- core Agent：miniprogram/lib/core.js 和 tests/core.test.cjs、tests/subject-core.test.cjs、tests/archive-core.test.cjs、tests/category-core.test.cjs；当前分类核心已交付，未经重新分配不改。
- native Agent：单独分配的页面、帮助页、折线组件及相关文件；不改核心，不接管根 Agent 的存储工作。
- QA Agent：只读源码，写其单独分配的测试/审查产物；不得与实现者同写。
- 文档 Agent：仅本目录 README.md、CONTRACT.md、微信小程序开发与上架指引.md、AGENTS.md、miniprogram/native-help.md，以及父 README 小程序首段；design-contract.md 由根 Agent 管理，不得修改，不写验收记录、QA、源码、配置、打包、治理或桌面历史。完成后交还写入权。

0.5.0 的大面积暖白、焦橙、深棕方案已被用户否定；其预览和测试只作历史证据。0.6.0 是新的候选方向，尚不能称为获用户视觉认可；当前生成、验证及手机状态统一见验收记录。历史 [0.5.0 开发预览码](release/微信开发预览码-0.5.0.png) 保留，不将其结果改标为 0.6.0。

一个文件集同时只有一个写者；以根 Agent 的明确分配和交权为准，不得用旧分工扩大授权。

单教师、单设备、本地数据；不接模型、不做云同步。2026-10-07 用户已要求推进上架，先完成上传与对应材料；实际已做步骤以新上传记录为准，不把授权当作已发布。每份档案一个学科，本版 Native 新档填写称呼和年级，固定显示英语，预选当前分类且允许未分类；核心兼容范围不能当作本版多学科入口。首页称“份档案”而非去重人数。首次 10 份英语示例分为小学英语 4、初中英语 3、高中英语 3，默认满分 100/120/150，每档 4 条成绩，共 40 成绩、8 标签、1 计划，均为普通可编辑删除记录，不限制可用年级。成绩与标签是手工记录，建议用教师选择的已学材料，是可解释草稿，不是诊断或掌握度结论。

schemaVersion 为 4，可读 1/2/3/4；旧 className 隐藏保留，仅 v1/v2 在唯一明确科目时推导档案学科，混科或未知留待整理，不拆分、不合并、不混线。v3 学科与 isExample 原样保留。v1/v2/v3 分类列表迁移为空、categoryId 为空，统一归未分类，不自动补示例或猜分类。旧档案/导入历史不得因英语定位静默改科。存储键继续使用 student-manager-lite.v3.archive，内容升级到 4；无此键读旧 personal，读取不写回，首次成功保存/恢复迁移，旧键保留。已有空库不自动添示例，删空不自动重种，不得用示例覆盖旧档案。自 0.3.1 起，首页无示例时允许用户直接点击“添加 10 个示例学员”，无额外确认弹窗；core.addExampleStudents 原子追加，复用同名分类并保留其 total，示例成绩按比例适配，不要求清缓存。已有任一示例时拒绝重复追加，删除后不自动复活。

分类名称规范化去重，最多 100 类，默认满分为正有限数且不超过 1000000。新成绩只在省略满分时继承所选分类默认值；修改分类满分或移动学员不改历史成绩。有学员引用的分类拒绝删除，需先移出；删除学员仍按原确认级联记录。备份包含全部分类及其默认满分，恢复预检须提示完整替换范围。原生页面新增从成绩记观察、复用同依据待跟进计划、完成后空白复测入口，已通过历史 0.3.0 官方模拟器检查；不得把合成 mock 存储的结果冒称为手机真实持久化通过。
